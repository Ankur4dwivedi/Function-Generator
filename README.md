# Four-Waveform Function Generator Using LTspice

## Project Overview

This project involves the design and simulation of a **Four-Waveform Function Generator** using LTspice. The circuit is designed to generate four different waveforms: Sine, Ramp, Triangular, and Sinc.

The system uses an H-bridge-based switching configuration controlled through PWL (Piecewise Linear) files. Each waveform is generated by applying specific switching sequences to the circuit. A multiplexer is incorporated to select and combine the four waveform-generation paths into a single circuit, allowing the user to obtain the desired waveform from one integrated system.

## Waveforms Generated

The function generator is capable of producing the following four waveforms:

1. **Sine Wave** – A sinusoidal waveform.
2. **Ramp Wave** – A linearly increasing or decreasing waveform.
3. **Triangular Wave** – A periodic waveform with linear rising and falling slopes.
4. **Sinc Wave** – A waveform based on the mathematical sinc function.

## Circuit Architecture

The project consists of the following major sections:

### 1. H-Bridge Configuration

- Implemented an H-bridge switching topology.
- Used switching elements to control the waveform generation process.
- Designed the switching arrangement to produce different waveform patterns.

### 2. PWL-Based Switching Control

- Used PWL (Piecewise Linear) files to define switching signals.
- Created separate switching sequences for the four waveform-generation modes.
- Controlled the switching elements using predefined voltage-time sequences.

### 3. Multiplexer

- Integrated a multiplexer to select between the four waveform-generation paths.
- Enabled multiple waveform outputs to be handled within a single circuit.
- Simplified waveform selection and circuit integration.

### 4. DC Supply Section

- Incorporated DC supply circuitry to provide the required operating voltages.
- Integrated the supply section with the switching and waveform-generation stages.
